# Интерактивный образовательный сайт «Площади сложных фигур» (Математика, 5 класс)

Полноценный интерактивный цифровой урок по теме **«Нахождение площади фигур, состоящих из прямоугольников и треугольников»**, разработанный специально для проведения занятий на большой интерактивной электронной доске, компьютере и мобильных устройствах.

---

## 🚀 Быстрый запуск проекта

Проект работает полностью локально на чистом **HTML5 + CSS3 + JavaScript + SVG + Web Speech API** и не требует подключения к интернету или установки платных сервисов.

### Вариант 1. Прямое открытие в браузере
Дважды нажмите на файл `index.html` в папке проекта — урок сразу откроется в вашем браузере (Google Chrome, Microsoft Edge, Яндекс.Браузер, Firefox, Safari).

### Вариант 2. Запуск через локальный веб-сервер (рекомендуется для интерактивных досок)
В терминале в папке проекта выполните одну из команд:
```bash
# Через Python 3:
python -m http.server 8080

# Или через Node.js (npx):
npx serve -l 8080
```
После этого откройте в браузере адрес: `http://localhost:8080`.

## 📚 Методическая архитектура урока (от простого к сложному)

1. **Уровень 1. Вспоминаем изученное**:
   - Площадь прямоугольника $6 \times 4\text{ см} = 24\text{ см}^2$ с пошаговой анимацией заполнения единичными клетками ряд за рядом.
   - Площадь треугольника $a = 8\text{ см}, h = 4\text{ см}$ ($S = (8 \times 4) : 2 = 16\text{ см}^2$) с наглядной демонстрацией разделения прямоугольника диагональю на два равных треугольника.
   - Мини-проверка из 3 задач с автоматической проверкой.
2. **Уровень 2. Знакомимся со сложными фигурами**:
   - Демонстрация плавного соединения двух прямоугольников в единый L-образный контур.
   - 10-шаговая анимация разделения фигуры ($8 \times 3\text{ см}$ и $4 \times 2\text{ см}$, $S = 24 + 8 = 32\text{ см}^2$).
   - Мини-проверка из 3 задач.
3. **Уровень 3. Фигура из прямоугольника и треугольника**:
   - Интерактивный разбор фигуры из прямоугольника ($6 \times 4\text{ см}$) и треугольника ($a = 4\text{ см}, h = 6\text{ см}$), $S = 24 + 12 = 36\text{ см}^2$.
   - Прямое нажатие пальцем на части фигуры на доске подсвечивает выбранную часть и её формулу.
4. **Уровень 4. Фигуры из трёх и более частей**:
   - Предварительный вопрос классу на выбор способа разбиения и 11-шаговая визуализация (включая пример $6 \times 4$, $3 \times 4$ и треугольник $4 \times 3 \implies S = 24 + 12 + 6 = 42\text{ см}^2$).
5. **Уровень 5. Учимся самостоятельно разбирать сложные фигуры (Два способа решения)**:
   - Интерактивный выбор линии разреза на электронной доске.
   - Наглядное сравнение **Способа №1** (два прямоугольника и треугольник) и **Способа №2** (один прямоугольник и два треугольника) с доказательством равенства итоговой площади.
6. **Уровень 6. Сложные задания и самостоятельная работа**:
   - 6 комплексных задач, завершающихся финальной задачей из 5 частей «Замок Геометрии».
7. **Раздел «Учимся думать самостоятельно»**:
   - Пошаговый диалог: выбор разбиения → выбор формулы для каждой части → вычисление площадей частей → сложение.
8. **Тренажёр (20 задач)**:
   - 5 лёгких, 5 несложных, 5 средних и 5 сложных задач с диагностикой причины ошибки (забыли разделить на 2 в треугольнике, ошибка в сложении частей, путаница с периметром).
9. **Интерактивная викторина (10 вопросов)** и **Заключительный раздел с 3 главными правилами**.
